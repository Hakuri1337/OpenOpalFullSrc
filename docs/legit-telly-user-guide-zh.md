# Legit Telly 使用教程

Legit Telly 是 Beta 专属的独立自动搭路模块。它不是 Scaffold 模式，也不能与 Scaffold 同时运行。模块会先检查朝向、俯视角、准星命中面、边缘站位和前方空间；全部满足后，才会接管移动、视角、切槽和放置。

## 推荐设置

- `Auto Swap`：开启。自动从快捷栏选择数量最多的安全完整方块。
- `Disable SafeWalk`：开启。启动时临时关闭 SafeWalk，结束后恢复原状态。
- `Anti Sway`：开启。降低路线横向偏移。
- `Actionbar Guide`：开启。动作栏会显示实时诊断和下一步操作。
- `Edge Hold`：默认 `1000 ms`。首次使用不建议调低。

## 启动前准备

1. 关闭 Scaffold。
2. 在快捷栏放入足量完整方块。不要使用台阶、楼梯、沙子、砂砾、箱子、工作台、TNT、植物等特殊方块。
3. 找到前方没有方块阻挡的平台边缘。
4. 开启 Legit Telly，并按照动作栏提示调整。

## 标准启动动作

1. 水平朝向对准斜向角：`45°`、`135°`、`225°` 或 `315°`，误差必须在约 `2°` 内。
2. 向下看，使 Pitch 达到 `75°` 或更大。
3. 将准星放到自己脚下方块朝前的侧面，不要瞄方块顶面。准星应位于该侧面的中央窄区。
4. 靠近前方边缘，并保持前方起步空间为空。
5. 按住潜行。动作栏会显示边缘锁定进度，默认需要稳定保持约 1 秒。
6. 出现“已锁定”后，先按住右键，再松开潜行。
7. 模块进入启动校准，随后自动运行。开始后可以松开右键。

简化记忆：

```text
斜向 45° → 低头看侧面 → 靠边潜行 1 秒 → 按住右键 → 松开潜行
```

## 如何停止

运行开始后，执行任一操作即可安全中止并归还控制：

- 按下任意移动键；
- 主动移动鼠标改变视角；
- 打开界面；
- 关闭模块；
- 开启 Scaffold；
- 服务器修正玩家位置。

AutoBucket 进入紧急状态时，Legit Telly 也会主动让出控制。

## 动作栏提示说明

- `① 水平朝向对准 45° 斜向`：Yaw 尚未进入允许误差。
- `① 继续向下看`：Pitch 小于 `75°`。
- `② 向前方边缘再靠近`：站位离起步边缘过远。
- `② 前方起步空间被阻挡`：换一个前方为空的位置。
- `② 瞄准脚下方块的前侧面`：准星未命中正确方块或命中了顶面。
- `② 将准星移到前侧面的中央窄区`：命中面正确，但落点区域不符合激活条件。
- `② 边缘锁定`：保持潜行、视角和站位，不要移动。
- `③ 已锁定`：按住右键，然后松开潜行。
- `④ 启动校准`：模块正在接管，不要手动输入。
- `⑤ 运行中`：模块正常运行，提示中会显示剩余可用方块数。

## 常见问题

### 一直提示角度不正确

使用调试界面查看 Yaw，并靠近四个斜向角。只看画面“差不多斜着”通常不够，允许误差约为 `2°`。

### 已低头，但提示不要瞄顶面

继续把准星向平台外侧下移，让射线命中脚下方块朝前的竖直侧面，而不是上表面。

### 锁定进度反复清零

锁定期间不能改变命中的方块、朝向、准星命中区域或潜行状态。首次使用保持默认 `Edge Hold = 1000 ms`。

### 右键后没有开始

正确顺序是“先保持右键按下，再松开潜行”。同时确保朝向仍在斜向角允许误差内。

### 提示没有安全方块

打开 `Auto Swap` 并把普通完整方块放入快捷栏；如果关闭了 `Auto Swap`，必须主动手持合法方块。

### 启动后立刻中止

不要在启动校准阶段按移动键或移动鼠标；检查 Scaffold 是否开启、方块是否耗尽，以及服务器是否修正了位置。
